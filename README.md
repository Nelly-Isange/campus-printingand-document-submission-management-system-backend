# Campus Printing and Document Submission Management System

Isange Nelly · 27818 · INSY 8322 Web Technology and Internet

Students, printers, print services, operators, and print requests, with lookups by student name, request status, request date, print service, free printers, unused services, and an operator's students. A new request stays submitted, cannot use a past date, and an operator can hold only one active request on a day. Status, print services, and the assigned printer are changed on their own. A payment is saved only for a ready request, listed for that student with the newest date first, and must be deleted before the request. Requests can be counted by status, and every request for an operator on one day can be cancelled except a ready one. The dashboard counts students, operators, free printers, today's requests, submitted requests, and payments, and print requests can be listed one page at a time.
